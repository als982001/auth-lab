2. 현재 상태

access token
없음 (메모리 변수)
refreshToken (JS)
읽을 수 없음 ✅ (httpOnly)
그 외 쿠키
없음

로그인해도 refreshToken은 계속 "읽을 수 없음"이어야 한다 — httpOnly라 JS가 접근할 수 없기 때문. curl로는 확인할 수 없던 부분이다.

"그 외 쿠키"에 낯선 값이 보인다면 다른 localhost 프로젝트 것이다. 쿠키는 포트를 구분하지 않아서 localhost:3000과 localhost:5173이 같은 저장소를 공유한다 (CORS는 포트를 구분하는데 쿠키는 안 한다). 그것들이 여기 보이는 것 자체가 httpOnly가 아니라는 뜻이고, 우리 것과의 대조군이 된다.

3. 요청

access 버리기 → GET /me (401 확인) → POST /auth/refresh → 다시 GET /me (200) 순서로 눌러보면 재발급 흐름 전체를 볼 수 있다. 새로고침해도 같다 — access는 메모리라 날아가지만 refresh 쿠키는 살아있다.
